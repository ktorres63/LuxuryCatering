# Carpeta de imágenes

Aquí van los recursos gráficos de la web. Cuando el cliente entregue sus fotografías reales,
reemplazar los placeholders manteniendo los mismos nombres de archivo para no tocar el código.

Subdirectorios sugeridos:

- `hero/` — fotografía a sangre para la portada (Hero).
- `services/` — una imagen por cada servicio del arreglo `src/data/services.ts`.
- `events/` — imágenes para cada tipo de evento en `src/data/events.ts`.
- `team/` — foto del equipo para "Sobre nosotros".
- `gallery/` — fotos para la galería, referenciadas desde `src/data/gallery.ts`.

Por ahora puede dejarse con placeholders (SVG discretos) o vacío; las rutas en `src/data/*.ts`
deben apuntar a estos nombres.
